| 文件 | 覆盖的组件 |
|---|---|
| `MIT.txt` | **只有我们自己写的文件**（构建脚本、`docs/`、`使用说明/`、三生自研 Lua、图标与主题、README） |
| `LGPL-3.0.txt` | `rime/rime-wubi`（`wubi86.dict.yaml`、`wubi_pinyin.schema.yaml`） |
| `Apache-2.0.txt` | `KyleBing/rime-wubi86-jidian`、`rime/rime-pinyin-simp`、OpenCC |
| `MIT-ECDICT.txt` | `skywind3000/ECDICT`（`en2zh_v2_*` 的数据源） |
| `CC-BY-SA-4.0.txt` | CC-CEDICT（`zh2en_pinyin_wp` / `zh2en_wubi_wp` 的数据源，**具传染性，不能并入 MIT**） |
