## 2. 应用介绍（长描述，用户视角）

三生输入法是一款运行在 HarmonyOS 上的本地输入法。它把五笔、拼音和英文放在同一个键盘里，
不需要切换输入法，也不需要记住别人设计的规则。

**打拼音，看见五笔码。** 输入 `nihao`，候选栏上方的反查行给出这一串对应的五笔码；
点候选栏右端的展开按钮把候选摊成网格后，每一格上方都带着自己那个词的码。想学五笔、或者五笔拼音混着用的时候，这一条就够省事了。

**打五笔，反查读音。** 输入五笔码，反查行给出候选的拼音（多音字列全部读音），生僻字、不确定读音的字也能打出来。

**九宫格也能打三向。** 智能九键下输入 `64 426`，屏幕显示 `ni hao`，候选给出「你好 / 你敢 / 米高」，
和 26 键一样支持拼音、五笔、英文三向。

**候选不够就展开。** 候选栏一键展开成网格，每页可左右滑动翻页，长词、多音词、同音词一次挑完。

**词库随包，不联网。** 所有词库和处理都在本机完成，应用不申请网络权限，不上传、不收集任何个人信息。
你的输入内容只留在你自己的设备上。

**自动调频。** 选过的词会记住，常用的排到前面；简繁切换、符号与 Emoji 面板、横屏键盘均已支持。

1.0.0 为首个上架版本，覆盖 26 键与九宫格两套布局、五笔 / 拼音 / 英文三向互译混输与三向反查、
自动调频、符号与 Emoji、简繁切换、横屏适配。

## 3. 版本说明（发布文案，1.0.0）

首个正式版本。

- 五笔 · 拼音 · 英文三向混输，同一键盘内直接切换，无需换输入法
- 三向反查：拼音输入时反查行给出五笔码，五笔输入时给出拼音与全部多音读音；展开网格后每格自带对方那套码
- 智能九宫格：T9 数字输入同样支持三向，含拼音提示与多词候选
- 候选栏单行显示、预编辑独立成行；可展开为网格，左右滑动翻页
- 自动调频：选过的词优先出现；简繁切换、符号与 Emoji 面板、横屏布局
- 全程本机处理，不联网、不申请网络权限、不收集个人信息
