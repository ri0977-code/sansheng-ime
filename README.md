# 三生输入法（原「五笔词通」）

Rime 五笔拼音输入法增强滤镜：给候选词加 **编码反查**（五笔码 + 拼音）与 **多音字注释**，
完全不改输入法原文件，独立 Lua 滤镜，安全可卸。

> 项目原名「五笔词通」，2026-10-15 更名为「三生输入法」。

## 功能

- **真·反查（按输入类型回显对方那套码）**：
  - 打五笔 `vb` → 好 显示 `hao`（只回显拼音）；
  - 打拼音 `hao` → 好 显示 `[vb]`（只回显五笔码）；
  - 打英文 `good` → 好 显示 `hao [vb]`（查义场景给「拼音 + 五笔码」最全信息）。
  - 通过比对「输入串」与候选自身的五笔码/拼音判定，不误伤「五笔码含元音键」的常见字（不=i、有=e、和=a 等）。
- **拼音注释**：打五笔时由本滤镜拼音表回显（可靠，不漏 好→hao 等）；打拼音时本滤镜剥掉上游拼音只留五笔码；打英文时与五笔码并列显示（拼音 + 五笔码）。
- **多音字注释**：单字多音字在打五笔时列出全部读音，如 打 `ta` → 长 显示 `zhang/chang`；打拼音 `zhang` → 长 显示 `[ta]`。
- **注释格式**：`[五笔码]`（打拼音时前置）；`拼音 [五笔码]`（打英文时）；`拼音 / 全部读音`（打五笔时）。均置最前，不被截断。

## 反查来源与准确性（重要）

- 五笔码只显示两种**可靠**来源：
  1. 词库实码（`wubi86` 主词库 / 万能五笔自造词 / `user.txt` 用户真实词条）；
  2. 按**标准五笔组词规则**现算的码（四字词每字首码等），**但若该码已被另一个多字词占用则隐藏**，避免误导。
     - 例：`海洋生物 → [iitt]`（海i 洋i 生t 物t，与单字「沙→iitt」共存，正常显示）；
     - 例：`家乡的茶` 现算 `pxra`，但 `pxra` 已被真实词「它找」占用 → **不显示**，只给拼音。
- 拼音来自全量拼音词典 `cn_pinyin_wp`；生僻字（如扩展B区 `𧟴`）无拼音收录时只显示五笔码，属正常。

## 安装

1. 备份你的 Rime 目录（`D:\Program Files\Rime` 或 `%APPDATA%\Rime`）。
2. 复制 `codeLookup_Filter.lua` → Rime 主目录的 `lua/` 子目录。
3. `rime.lua` 末尾追加（若已存在可跳过）：
   ```lua
   codeLookup_Filter = require("codeLookup_Filter")
   ```
4. `wubi_pinyin.custom.yaml` 的 `engine/filters:` 中，`pinyinAdding_Filter` 之后插入：
   ```yaml
   - lua_filter@codeLookup_Filter
   ```
5. **重新部署**：Rime 托盘图标 →【重新部署】（重编译方案并加载新 Lua）。

## 设计原则（踩坑总结）

1. 独立文件，绝不整文件替换 `inputShow_Filter.lua`（dsh 旧方案「修一个坏一个」）。
2. 全程 `pcall` + `cand:get_genuine().comment`，任一候选出错不影响输入，**调频/自造词不受影响**。
3. 只改 `comment`，不改候选顺序与身份。
4. **绝不手动往词典里塞词**——遵循 Rime 自动组词（连续上屏后写入 `user.txt`，反查自动读取）。
5. `user.txt` 的 `enc*` 自动编码条目不是规范五笔码，已过滤，不参与反查。

## 版本沿革

- 更名前（五笔词通）：v2.0 初版反查 → v2.1 修复坏组词逻辑 → v3.0 恢复拼音反查 + 碰撞检测 + 移除手动词典。
- **v1.0（2026-10-15，更名基线）** ＝ 原「五笔词通 v3.0」：拼音反查恢复(逐字首选读音) + 碰撞检测 + 移除手动词典 + `user.txt`(tabledb) 正确加载。
- **v1.1（2026-10-15，本轮修复）**：
  1. 拼音注释改由上游 `pinyinAdding_Filter` 负责，本滤镜不再重复追加，消除「打拼音时注释里多出一份拼音」。
  2. 五笔反查码前置 `[五笔码] 其余`，保证始终可见不被末尾截断（如 good→好 的 vbrq）。
  3. 碰撞隐藏逻辑保留（家乡的茶 pxra 与 它找 撞车 → 不显示，避免误导）。
  4. 不手动塞词原则不变。
- **v1.2（2026-10-16，恢复“真反查”语义）**：
  1. 打五笔只回显拼音、打拼音/英文只回显五笔（各显示对方那套码），消除 v1.1「两套都显示」的多余码。
  2. 判定方式：比对「输入串」与候选自身的五笔码/拼音，不误伤「五笔码含元音键」的常见字（不=i、有=e、和=a 等）。
  3. 单字多音字在打五笔时升级为全部读音（长 → zhang/chang）。
- **v1.3（2026-10-16，修复反查不对称 + 截断）**：
  1. 五笔输入分支改为【主动用本滤镜拼音表把拼音置最前】，修复上游 `pinyinAdding` 覆盖不全（有 `大→da/dai` 却漏 `好→hao`、`少→shao`）导致 `vb→好` / `it→少` 不显拼音。
  2. 拼音/英文输入分支把五笔码【置最前】，不再甩在末尾（修复 `good→好` 的 `vbrq` 因居末被截断看不到）。
  3. 真反查两条主轴不变：五笔输入只回显拼音、拼音输入只回显五笔。
- **v1.4（2026-10-16，英文反查补回拼音）**：
  1. 根因：v1.3 把「英文/其它」输入归类为「回显五笔码并剥掉拼音」，导致 `good→好` 只见 `[vb]` 不见 `hao`、`small→小` 只见 `[ih]` 不见 `xiao`。
  2. 修复：英文/其它输入改为回显「拼音 + 五笔码」（最全），如 `good→好` 显示 `hao [vb]`、`small→小` 显示 `xiao [ih]`。
  3. 五笔/拼音两条主轴不变；英文作为「查义」场景给最全信息。

> 注：`家乡的茶 / 家乡的狗 / 家乡的水` 等是你的**自造词**，在 `user.txt` 中存为 Rime 自动生成的 `enc*` 占位码（非规范五笔码），故反查不显示码；其自然码 `pxra` 又被真实词「它找」占用，所以打 pxra 出的是「它找」。要让自造词用干净码打出，需在 `user.txt` 给它们配真实五笔码（此举会与「它找」抢 pxra，需权衡）。
