# 五笔词通 · 手动安装指南（bat 用不了时看这份）

> 什么时候用这份：`install.bat` 双击闪退、显示乱码、报「没找到小狼毫目录」、或者你根本不想跑脚本。
> 全程约 3 分钟，只需复制粘贴 + 右键菜单。

---

## 第 0 步：确认前提

1. 装了 **小狼毫（Weasel）0.17.4 或更新版**
   没装就先去下：https://github.com/rime/weasel/releases
2. 把本包**完整解压**（不能直接在压缩包里操作）

---

## 第 1 步：找到小狼毫的安装目录（Rime 目录）

**这个目录长这样，里面一定有 `installation.yaml` 和 `build` 两个文件夹。**

按顺序试这几种方法，找到就记住路径：

### 方法 A：从托盘反查（最准，30 秒）

1. 看任务栏右下角托盘，找到小狼毫图标（一只灰色狼头）
2. **右键 → 用户文件夹**（或「打开用户文件夹」）
3. 弹出的窗口就是 Rime 目录

> 小提示：托盘图标可能被折叠在 `^` 那个小箭头里。

### 方法 B：开始菜单搜索

按 `Win` 键 → 输入 `rime` → 右键「小狼毫」→ **打开文件所在的位置** → 再右键 `rime.exe` → **打开文件所在的位置**。

### 方法 C：常见路径手动翻

挨个检查这几个，**哪个里面有 `installation.yaml` 就是它**：

```
C:\Program Files\Rime
C:\Program Files (x86)\Rime
C:\Users\你的用户名\AppData\Roaming\Rime
D:\Program Files\Rime
D:\Rime
E:\Program Files\Rime
```

**找不到？** 用资源管理器搜索：随便打开 `C:\`，右上角搜索框输入 `installation.yaml`，勾选「整个电脑」慢慢等。搜到后看它的上级目录。

---

## 第 2 步：备份原配置（建议做，出问题能退回去）

在 Rime 目录里新建一个文件夹，命名 `_wbcitong_backup`，
把原有的这些文件拖进去（有就拖，没有就跳过）：

```
wubi_pinyin.schema.yaml
wubi_pinyin.custom.yaml
default.custom.yaml
wubi86.dict.yaml
wubi86_jidian.dict.yaml
lua\inputShow_Filter.lua
```

---

## 第 3 步：复制文件（核心一步）

打开本包的 `rime` 文件夹。

**第一步：复制根目录的 18 个文件**

全选 `rime` 文件夹里**根层**的所有 `.yaml` 文件，按 `Ctrl+C`。

打开第 1 步找到的 **Rime 目录**，按 `Ctrl+V`，提示「是否替换」时选**全部替换**。

> 注意：只复制**根层**的文件。`lua` 是子目录，下一步单独处理。

**第二步：复制 lua 滤镜**

把 `rime` 文件夹里的 `lua` 文件夹整个复制到 Rime 目录。
如果 Rime 目录已有 `lua` 文件夹，就把 `lua` 里的 `.lua` 文件复制进去（覆盖）。

**第三步：旧的「万能五笔自造词」文件不用管**

以前包里有 `我的自造词_可选\`（4 个 `wnwb_*_wp.dict.yaml`），**v1.9.11 / v1.10 起已经不再提供**，
所以这一层什么都不用做。如果你 Rime 目录里还留着老的 `wnwb_*.dict.yaml`，新配置已经不再引用它们，
留着不影响使用；想清理干净，手动删掉这几个文件即可（它们在 `wubi86.dict.yaml` 里已经没有引用行）。

---

## 第 4 步：重新部署（**这步不做，复制了也不生效**）

1. 托盘右键小狼毫 → **退出**
2. 重新双击打开小狼毫
3. 托盘右键 → **重新部署**
4. 等它跑完（可能十几秒）

---

## 第 5 步：切换方案并验证

按 `F4`，选择「**五笔·拼音**」，然后测试：

| 输入 | 期望 |
|---|---|
| `vb` | 第 1 个是「好」，附近有 good |
| `hao` | 第 1 个是「好」，附近有 good |
| `agjs` | 苹果 + Apple |
| `good` | 好 / 好处 / 好的 |

## 常见问题

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 复制完还是原来的输入法 | 漏了「重新部署」 | 退出小狼毫 → 重开 → 重新部署 |
| `F4` 里没有「五笔·拼音」 | 文件没复制到位 | 确认 Rime 目录里有 `wubi_pinyin.schema.yaml` 和 `default.custom.yaml` |
| 方案列表变成空的 | `default.custom.yaml` 没覆盖成功 | 从备份恢复，再手动重复制 |
| 双击 bat 一闪而过 | 权限不足 | 右键 bat → **以管理员身份运行** |
| bat 显示乱码 | 系统区域设置非简体中文 | 直接用这份手动指南，不跑 bat |
| 提示「找不到 Rime 目录」 | 小狼毫装在特殊路径 | 用第 1 步方法 A/C 找到，手动复制 |

---

## 回退方法

如果装完不满意：

1. 托盘右键小狼毫 → 退出
2. 把 `_wbcitong_backup` 里的文件复制回 Rime 目录
3. 重新部署
