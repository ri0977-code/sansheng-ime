## 4. 一个已知瑕疵（记下来，不掩盖）

`accepted-20261030-071035\content-gate.txt` 里的中文是**乱码**（`瀵硅薄:`…）。
根因：`release_build.ps1:305` 用 `Tee-Object` 捕获 python 输出，而 Windows PowerShell 5.1
按本地代码页（GBK）解码子进程的 UTF-8 字节 ⇒ 捕获到的字符串已经错位，再按 UTF-8 写盘就成了 mojibake。
**受影响的只是归档里的这份日志文本**，不是包内容、不是退出码（`$LASTEXITCODE` 独立传递，闸门确实跑了并返回 0）。
所以本目录另存了一份**干净复跑**的输出（不经 PowerShell 管道）。
是否要改 `release_build.ps1` 里那行捕获方式（例如 `$env:PYTHONIOENCODING` 之外再设 `[Console]::OutputEncoding`）
＝动构建脚本，**未获指派前我不动**，只在此登记。
