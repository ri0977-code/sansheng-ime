# 隐私政策 / Privacy Policy

更新日期：2026-10-20

三生输入法（Sansheng IME）是运行在本机的 Windows 输入法配置与增强组件。本政策说明它会接触哪些数据、数据存放在哪里，以及什么时候会联网。

## 我们收集什么

**不收集。** 本项目没有账号系统、遥测、使用统计、广告或崩溃上报，也不收集按键、候选词、输入内容、剪贴板、设备信息或位置信息。

## 数据存放在哪里

- 词库、用户自造词（`user.txt`、`Custom_phrase.txt`）、调频记录与配置都保存在本机：
  - Rime 用户目录（默认 `%APPDATA%\Rime`，若你安装官方小狼毫时改过路径，则以该路径为准）；
  - 程序安装目录。
- 安装或升级前，安装器会在 Rime 用户目录内创建 `sansheng-backup-时间戳`，备份现有的 `*.yaml`、`*.txt`、`*.lua`、`*.json` 与 `lua/`、`opencc/` 目录，便于回滚。备份同样只在本机。
- 打字记录（`*.userdb`）与 `sync/` 不在备份或覆盖范围内。
- 本项目默认不开启 Rime 同步。如果你自行在 `installation.yaml` 里配置同步目录（例如网盘），数据会写入你选择的服务，受该服务的隐私政策约束。

## 网络访问

- 安装包本身不联网，安装过程不下载任何额外组件。
- 安装时会写入 `CheckForUpdates=0`，关闭上游小狼毫的自动更新检查，避免它在后台替换引擎。
- 只有你**手动**运行开始菜单里的「检查更新」时，才会访问 GitHub Releases 查询最新版本，并可选下载安装包；该工具只读取已安装版本号，不读取词库或输入内容。
- 从 GitHub 下载安装包时，GitHub 可能按其自身隐私政策记录访问日志。

## 第三方组件

- 安装包内含 [rime/weasel 0.17.4](https://github.com/rime/weasel) 的未修改二进制（GPLv3）及 OpenCC 等上游数据。它们在本机运行，不向本项目回传数据。
- 输入法框架由 Windows TSF 提供；Windows 自身的诊断与错误报告由操作系统控制，与本项目无关。

## 儿童隐私

本项目不面向儿童收集任何数据。
