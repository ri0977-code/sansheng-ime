# H-254 真机取证：`···` 菜单行点完之后底色必须回到常态

Qoder 2026-10-28 09:0x。装机包 unsigned 28,501,123 B／signed 28,627,631 B。

## 这是什么毛病

`···` 菜单里每一行（`FuncMenuItem` 12 行 ＋ 底部「设置（键盘与候选）」行）**点过一次就停在按压色**，
直到把菜单关掉重开才恢复。真机量到的值：按压 `(219,226,236)` ＝ `FUNC_ICON_PRESSED #DCE2EC`，
常态 `(242,243,245)`。

根因与主人 10-28 01:2x 报的 **H-238**（顶栏 ⇆ 折叠后灰底不恢复）相同：ArkUI
`stateStyles({pressed: …})` 在这次重渲染里抬手不复位。只是 H-238 落在工具栏图标上，
这次落在菜单行上——同族病第二次落地，所以守卫从「散文提醒」升级成「拦截」。

## 怎么量（不用肉眼）

`scripts/h254_menu_row_press_check.py`：

1. 取菜单卡片里每条**文字带**的中心 y（行距 32vp×3.5＝112px）；
2. 在行带 ±22px、卡片内左右各留 10px 的范围里统计像素，**取众数颜色当底色**
   （文字/开关是少数像素，众数能剔掉）；
3. 点一下 → 等 1.0s（动画走完）→ 再取同一带同一行的众数；
4. 判据：与按压色 `(219,226,236)` 差 ≤8 ⇒ FAIL；与点前色差 ≤8 ⇒ PASS；
5. 同一条带**再点一次把开关拨回原值**，复原后再量一次。
