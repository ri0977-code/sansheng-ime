# H-155 第二批测试用例（三生输入法·鸿蒙）

> 真机人工验证（Mate80 `7GL0226408083897`）。不做设备自动测试，按用户 2026-10-23 确认。

## 前置
1. Mate80 已 `hdc install -r` 本批 signed HAP，`hdc shell ime -s com.sansheng.ime` 切回三生。
2. 打开"备忘录"新建一条，输入若干文字，光标停在文中（用于验证 a/s/v/c 编辑框操作）。
3. 准备一个含文字的剪贴板（用于验证 v=粘贴）。

## 用例

### TC-1 a 长按 = 全选
- 操作：在备忘录输入框，长按键盘 `a` 键（约 500ms）。
- 预期：编辑框内全部文字进入选中态；输入法**不**上屏字符 `a`。
- 判定：PASS / FAIL

### TC-2 s 长按 = 剪切
- 前置：TC-1 后文字已全选。
- 操作：长按 `s`。
- 预期：选区被剪切（文字消失进剪贴板）；不上屏 `s`。
- 判定：PASS / FAIL

### TC-3 c 长按 = 复制
- 前置：重新输入并选中一段文字。
- 操作：长按 `c`。
- 预期：选区被复制（文字保留，剪贴板更新）；不上屏 `c`。
- 判定：PASS / FAIL

### TC-4 v 长按 = 粘贴
- 前置：剪贴板有 TC-2/TC-3 复制的内容。
- 操作：光标置于空白处，长按 `v`。
- 预期：剪贴板内容粘贴到光标处；不上屏 `v`。
- 注意：若宿主 app 未申请 READ_PASTEBOARD，可能静默失败——换备忘录验证；记录是否为权限导致。
- 判定：PASS / FAIL（注明是否权限限制）

### TC-5 e 长按 = 气泡隐藏符号
- 操作：长按 `e`（非 a/s/v/c）。
- 预期：键面上方出现气泡，含 `é è ê ë ē € E` 等符号，首个高亮。
- 判定：PASS / FAIL

### TC-6 气泡滑动选择 + 松手上屏
- 操作：长按 `e` 出现气泡后，手指不抬起、向右滑动到 `è`，松手。
- 预期：`è` 上屏，气泡消失。
- 判定：PASS / FAIL

### TC-7 气泡松手取消
- 操作：长按 `e` 出现气泡后，手指滑到气泡外空隙再松手。
- 预期：无输入，气泡消失。
- 判定：PASS / FAIL

### TC-8 上滑/下滑不被长按破坏（H-154 回归）
- 操作：上滑 `e` → 应出 ALT 二级字符；下滑 `e` → 应出 `E`。
- 预期：与 H-154 行为一致，上滑符号 / 下滑大写正常。
- 判定：PASS / FAIL

### TC-9 短按不串
- 操作：分别短按 `a` `s` `v` `c` `e`。
- 预期：各自正常上屏对应字母；无全选/剪切/复制/粘贴/气泡误触发。
- 判定：PASS / FAIL

### TC-10 退格 / 空格 H-154 行为不变
- 操作：退格上滑清空、下滑撤销；看空格键文案为"三生"。
- 预期：与 H-154 一致。
- 判定：PASS / FAIL
