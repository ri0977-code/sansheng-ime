# 发布归档（内部工作记录）

这里放的是**每个版本对外发布时的内部工作文档**：发布页正文原稿、GitHub 发布步骤、双端合并清单、
回退预案、词库层下架预案。它们记录的是「当时怎么发的」，不是给装机用户看的说明。

- 想看**现在该装哪个包**：根目录 [README.md](../../README.md) 的「下载」一节。
- 想看**每个版本改了什么、怎么实测的**：[CHANGELOG.md](../../CHANGELOG.md)。
- 想**自己重新打包**：[docs/构建与发布.md](../构建与发布.md)。
