# 五笔词通 · 五笔拼音中英混输自造词

一套基于 [Rime /小狼毫](https://github.com/rime/weasel) 的中文输入法方案。

**五笔字型 + 汉语拼音混输 + 中英双向翻译 + 自动造词**

---

## 能力

| 能力 | 说明 |
|---|---|
| 五笔 · 拼音混输 | 打五笔码或拼音都能出词，同一方案内自由切换 |
| 中 → 英 | 打 `vb`（好）候选出 good；打 `agjs`（苹果）出 Apple |
| 英 → 中 | 打 `good` 出「好 / 好处 / 好的」，10.6 万条英中词条 |
| 自动造词 | 打「刚」再打「需」上屏后，下次直接打 `mqfd` 出「刚需」 |
| 词频自适应 | 常用词随使用自动上移 |
| 简体 → 繁体 | 拼音混输·繁体方案 |

### 三个方案

| 方案 | 说明 |
|---|---|
| **五笔·拼音** | 主推，功能最全 |
| 拼音混输 | 偏拼音输入习惯 |
| 拼音混输·繁体 | 简入繁出 |

---

## 已知限制

**不支持整句翻译。** 词库是**词级**的（ECDICT 词典），打整句只会逐词匹配，没有句子级翻译能力。

---

## 安装（Windows）

### 前提
已安装**小狼毫（Weasel）0.17.4+**：https://github.com/rime/weasel/releases

### 步骤

1. 下载 [Releases](../../releases) 里的 `wubi-citong-v1.0.0.zip`，解压
2. **双击 `install.bat`** —— 自动定位Rime 目录、备份原配置、复制全部文件
3. 退出并重新打开小狼毫
4. 托盘右键 → **重新部署**
5. 按 `F4` 选「五笔·拼音」

### 验证

| 输入 | 期望 |
|---|---|
| `vb` | 「好」+ good |
| `hao` | 「好」+ good |
| `pingguo` / `agjs` | 苹果（+ Apple） |
| `good` | 好 / 好处 / 好的 |
| 打「刚」「需」→ `mqfd` | 「刚需」（自动造词） |
