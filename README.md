## 取意

**三**：三道横——上横阳、下横阴，中间一横是变数。太极核心、生生不息之变量生机。太极生两仪、两仪生三才，三才生万物；三生即**五笔 · 拼音 · 英文**全向混输。

## 核心功能

| 功能 | 说明 |
|------|------|
| 三向混输 | 五笔 / 拼音 / 英文同一输入框混打，不切模式 |
| 三向反查 | 打五笔显拼音码，打拼音显五笔码，打英文显中英双码 |
| 真英文输入 | 打 `appl` 联想出 `apple`，选词自动带空格，候选带中文注释 |
| 86/98 五笔 | 长按简/英键一键切换 |
| 简繁切换 | 一键 OpenCC 转换 |
| 自调频 | 选词即学习，越用越顺手 |
| 自联想 | 中文模式下根据上文联想下一个词 |
| 手工造词 | 编码后上屏自造词，置顶不被挤掉 |
| 斜杠符号 | `/szq` 出特殊符号，三端通用 |
| 三端同库 | Windows / 安卓 / 鸿蒙共用同一套词库与符号表 |

详细能力清单见 [功能清单.md](功能清单.md)。

## 各端操作说明

### 鸿蒙端（手机）

| 操作 | 功能 |
|------|------|
| 点「简/英」键 | 中 / 英文模式切换 |
| 长按「简/英」键 | 切换 86 / 98 版五笔（气泡提示） |
| Shift 键上滑 | 开关联想词 |
| 退格上滑 | 删到上一个词开头 |
| 退格下滑 | 恢复刚才删的内容 |
| 长按回车 | 弹出键盘操作说明卡片 |
| 空格左右滑 | 移动光标 |
| 字母键上滑 | 出数字 / 符号 |

### 安卓端（手机）

| 操作 | 功能 |
|------|------|
| 空格长按 | 开关联想词 |
| 句号键上滑 | 出半角英文点 `.` |
| 空格左右滑 | 移动光标 |
| `/` 斜杠 | 出符号速查菜单 |

### Windows 端（电脑）

| 操作 | 功能 |
|------|------|
| `Shift` | 中英文切换 |
| `Ctrl+Shift+F` | 简繁切换 |
| `F4` | 中英对照开关 |
| `/` 斜杠 | 符号速查（`/szq` 出特殊符号） |
