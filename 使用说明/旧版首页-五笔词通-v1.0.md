# 五笔词通 · 五笔拼音中英混输自造词

一套基于 [Rime /小狼毫](https://github.com/rime/weasel) 的中文输入法方案。

**五笔字型 + 汉语拼音混输 + 中英双向翻译 + 自动造词**

---

## 📦 下载安装

**→ [Releases](../../releases) 下载 `wubi-citong-v1.0.2.zip`**

完整解压 → 双击 `install.bat` → 等编译完 → `F4` 选「五笔·拼音」

不想用脚本？见 [`使用说明/手动安装指南.md`](使用说明/手动安装指南.md)（纯手工 3 分钟）

---

## 能力

| 能力 | 说明 |
|---|---|
| 五笔 · 拼音混输 | 打五笔码或拼音都能出词，同一方案内自由切换 |
| 中 → 英 | 打 `vb`（好）候选出 good；打 `agjs`（苹果）出 Apple |
| 英 → 中 | 打 `good` 出「好 / 好处 / 好的」，10.6 万条英中词条 |
| 自动造词 | 打「刚」再打「需」上屏后，下次直接打 `mqfd` 出「刚需」 |
| 词频自适应 | 常用词随使用自动上移 |
| 简体 → 繁体 | 拼音混输·繁体方案 |

### 三个方案

| 方案 | 说明 |
|---|---|
| **五笔·拼音** | 主推，功能最全 |
| 拼音混输 | 偏拼音输入习惯 |
| 拼音混输·繁体 | 简入繁出 |

---

## 已知限制

**不支持整句翻译。** 词库是**词级**的（ECDICT 词典），打整句只会逐词匹配，没有句子级翻译能力。

## 安装（Windows）

### 前提
已安装**小狼毫（Weasel）0.17.4+**：https://github.com/rime/weasel/releases

### 步骤

1. 下载 [Releases](../../releases) 里的 `wubi-citong-v1.0.2.zip`，**完整解压**（不要在压缩包里直接双击）
2. **双击 `install.bat`** —— 自动定位 Rime 目录、备份原配置、复制全部文件，并自动触发小狼毫重新部署
   - 脚本开头会先跑一次完整性自检，显示 `[OK] 全部检查通过，可以安装` 才继续
   - 窗口不会闪退：开头有一次 `pause`，结束时也有
   - 出问题看同目录的 `install-log.txt`
3. 等编译完成（首次约 1-2 分钟，`build` 目录文件数不再增加即完成）
4. 按 `F4` 选「**五笔·拼音**」

### 不想用脚本？

打开 [`使用说明/手动安装指南.md`](使用说明/手动安装指南.md)，纯手工 5 步，同样 3 分钟。

### 验证

| 输入 | 期望 |
|---|---|
| `vb` | 「好」+ good |
| `hao` | 「好」+ good |
| `pingguo` / `agjs` | 苹果（+ Apple） |
| `good` | 好 / 好处 / 好的 |
| 打「刚」「需」→ `mqfd` | 「刚需」（自动造词） |
