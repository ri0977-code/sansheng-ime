## 四、H-082：符号页第 3 行被底栏遮挡（新单，P1）

**实测像素**（`m8-m058-02-cat-paren.png`，x=640 一列的白色键帽区间）：

```
分类条   ~2030–2140  (110px)
第 1 行   2148–2256  (108px 可见 / 步距 147px)
第 2 行   2295–2403
第 3 行   2442–2572
底栏      2596–2664  ← 与第 3 行同区间，左列 x≈100 处实测白色区间 2129–2517 连成一片
键盘面板可用内容区 2030–2675 = 645px
```

需求侧：分类条 110 + 符号 3 行×147 + 底栏 147 = **698px > 645px，超出 53px**。溢出全部压在第 3 行与底栏的交界处。

**后果（都是看得见的）**：
1. `()` 页第 3 行第 3 格 = `_`（下划线）**整格空白**——基线靠下的字形正好落在底栏 `空格` 键背后，用户看到的是一个死键；
2. 第 3 行第 1 格 `)` 下半截被 `ABC` 键盖住；`{` `}` 同样被切；
3. `¥` 页第 3 行 9 个货币符号（₪ ₱ ₫ ₦ ₸ …）**全部只剩上半截**，`m8-h082-row3-clipped.png` 一眼可见；
4. 触摸区没坏（点 `_` 那格实测无输出是因为它落在底栏 `空格` 命中区，点 `¥` 页第 3 行则正常上屏 `₪₱₫`），所以这是**渲染遮挡**，不是死键——但按「屏上看得见变化」这条铁律，第 3 行等于没交付。

**建议修法（给 CodeArts 参考，不替他定）**：面板 5 段（分类条 + 3 行 + 底栏）在 645px 里等分 → 每段 ≤129px；或分类条压到 ~88px、四个键行各 139px。另外基线靠下的字形（`_` `` ` `` `，`）需要居中基线或加下内边距，否则压扁后照样被切。

## 五、H-081：`/xx` 符号直出端到端仍不可用（新单，P1，招牌功能）

### 5.1 配置层是对的
M-059 做的三件事（`symbols.yaml` + `symbols.custom.yaml` 进 rawfile、`punctuator/import_preset` 改 `symbols`、`port_rime_data.py` 停止替换该行）方向正确，`symbols.yaml` 实测 28,473 B 与安卓版 APK 内 `assets/usr/share/rime-data/symbols.yaml` 同尺寸。

### 5.2 但键盘侧没有任何一条路能把 `/` 送进引擎

实测两条唯一入口：

| 入口 | 操作 | 结果 |
|---|---|---|
| 26 键 `h` 上滑次级字符 | `swipe 771 2253 → 771 2100` | 文本框直接出现 `/`（`m8-h081-slash-swipe-direct-commit.png`），候选条空 → **commitText 直出，引擎没收到键** |
| 符号面板 `()` 页找 `[` | `click 704 2505` | 文本框出现半角 `[`，hilog `cand=0 all=0` → 同上；**期望是 ［ 【 〔 三选一** |

再看 `/` 本身在面板上**根本不可达**：
- `()` 分类绑 `english` 组（`KeyboardIndex.ets:125`，28 项：`~ \` ! @ # $ ^ & * ( ) - _ = + [ ] { } \ | ; : ' " , . < > / ?`），面板只渲染**前 19 项**（第 1 行数字 + 第 2 行 10 + 第 3 行 9），`/` 是第 27 项，被截断；
- `rawfile/symbols/symbols.json` 全 115 组逐组扫描，**没有任何一组含 `/`**（脚本输出 `tmp-slashgroups.txt`，命中 0 行）。

所以：**H-079 现在只有数据没有出口**。用户装上去以后，`/szd`、`/jd`、`/dc`、`/lm` 一个都打不出来，`[` 和 `'` 的多义标点也一样出不来。这正好是 M-058 引入的「次级字符上滑直出」和「面板键直出」两条路径共同造成的。

### 5.3 建议修法（方向，不替他写）
1. **符号面板按键 + 上滑次级字符**：非 `ascii_mode` 时改走 `inputKey()` 进 Rime（让 punctuator / symbols preset 生效），只有英文模式才 `commitText` 直出；
2. **让 `/` 可达**：`1?#` 首页补一个 `/`，或把 `english` 组做成可翻页（前 19 / 后 9），别静默截断；
3. **验收必须回到屏上**：`/szd` 出候选并上屏、`[` 出 ［ 【 〔、`'` 出 ‘’「」，且这三条要在**竖屏 26 键和九键两种布局**都过一遍。

### 5.4 参照系提醒
安卓版（nova 6，`com.sansheng.ime` 1.10.1）是唯一基准。当前 nova 6 的默认输入法已经是
`com.sansheng.ime/org.fcitx.fcitx5.android.input.FcitxInputMethodService`（我本轮只做了 `dumpsys window` 只读查看，**没动 nova 6 的输入法和任何数据**）。请负责真机的一方在 nova 6 上实测一次「用户到底怎么打出 `/szd`」，把键路径写进记录，再照着修鸿蒙侧。**用完记得还原 `com.baidu.input/.ImeService`。**
