# 三生输入法 Sansheng IME

![三生输入法图标：黑底金色汉字三](assets/icon-sansheng-black-gold-256.png)

> **太极八卦意，三生万物名。**
> 图标三道横：**上下两长横为阴 · 阳两仪**，**中短横为鱼眼**——太极核心、生生不息之变量生机。太极生两仪、两仪生三才，三才生万物；三生即**五笔 · 拼音 · 英文**全向混输。

Rime「**五笔 · 拼音 · 混输 · 简繁**」全能输入法的增强滤镜：给候选加 **三向编码反查**、**多音字注释**、**简繁切换**与**自调频**，完全不改输入法原文件，独立 Lua 滤镜，安全可卸。

原名「五笔词通」，2026-10-15 更名为「三生输入法」。

## 三向真·反查（核心能力）

按输入类型回显对方那套码，不误伤「五笔码含元音键」的常见字（不=i、有=e、和=a 等）：

- 打五笔 `vb` → 好 显示 `hao`（只回显拼音）；
- 打拼音 `hao` → 好 显示 `[vb]`（只回显五笔码）；
- 打英文 `good` → 好 显示 `hao [vb]`（查义场景给「拼音 + 五笔码」最全信息）。

其他能力：简繁反查（繁体候选同样可反查）、自造词反查（user.txt 真实词条）、
多音字注释（打 `ta` → 长 显示 `zhang/chang`）、保留上游词性/释义（💡）与拼音（✔）注释、
反查码前置不被截断、碰撞检测杜绝误导性假码（现算码被真实词占用则隐藏）。

### 反查来源与准确性

- 五笔码只显示两种**可靠**来源：① 词库实码（wubi86 / 万能五笔自造词 / user.txt 真实词条）；
  ② 按标准五笔组词规则现算的码，但若该码已被另一个多字词占用则隐藏。
- 拼音来自全量拼音词典 `cn_pinyin_wp`；生僻字无拼音收录时只显示五笔码，属正常。

## 自调频（v1.7 新增）

选词即学习，上屏即记忆——三档机制：

| 档位 | 机制 | 状态 |
|------|------|------|
| 自动档 | Rime 用户词典 userdb：每次选词 / 连续上屏都记录，同输入下已选候选自动提频前置 | ✅ 默认开启（`enable_user_dict` + `encode_commit_history`） |
| 手动档 | `Custom_phrase.txt` 置顶自造词：`initial_quality: 1`，永远排最前 | ✅ 随包附模板 |
| 重置档 | `reset-tune.bat`：一键清空学习记录，从头再学（删前自动备份） | ✅ 随包附工具 |

**兼容承诺**：三生滤镜只改 `comment`、永不动候选顺序与身份——调频 / 自动组词机制不受滤镜影响（已真机验证）。

## 安装

**v1.9 起改成真正的傻瓜式**：下载本页顶部的 `sansheng-ime-v1.9.10-setup.exe`，右键 → 以管理员身份运行 → 下一步到底，装完即用（安装包附件名用英文，避免大文件在网页上传时因中文名失败；程序内名称、开始菜单、托盘显示都还是「三生输入法」）。装完不需要重启就能切到三生；万一语言栏没出来，注销一次即可，不用重启整机。已经装过旧版三生：**直接覆盖安装即可，不用先卸载、也不用手动结束小狼毫进程**（v1.9.5 起安装器自己会先停服务再覆盖）。

**本机装过官方小狼毫（Rime Weasel）也不用先卸载**：v1.9.9 起会识别官方版并直接接管——先调用官方 `WeaselSetup.exe /u` 注销它，再清掉官方的卸载登记、开机自启和开始菜单，然后在**原安装目录**装上三生。原有同名配置会先备份到 `sansheng-backup-时间戳`；词库、`user.txt`、`*.userdb` 不动。图形安装时会弹一次确认，静默安装（`/S`）则自动继续。

自动完成的事：

0. **检测到官方小狼毫时先接管**：注销官方 TIP/CLSID、删除官方卸载登记与自启、清理官方开始菜单，再在原目录安装；不会留下两套输入法抢同一个 CLSID。接管后会把官方 WinSparkle 自动更新关掉（`CheckForUpdates=0`），免得它把三生的引擎和配置升回官方版；
1. 释放 Rime 引擎（小狼毫 0.17.4）到 `%ProgramFiles%\Rime`；
2. 检测当前 Rime 用户目录（已有则沿用）；铺配置前先把顶层 `*.yaml / *.txt / *.lua / *.json` 与 `lua/`、`opencc/` 备份成 `sansheng-backup-时间戳`，再用三生的同名配置覆盖；**`Custom_phrase.txt` 是用户自造词，已有就原样保留**（只有全新安装才写模板）；`*.userdb`（打字记录）、`user.txt`、`sync/`、`build/` 不动；
3. 铺设三生配置 + 中英文权重表 + OpenCC 简繁数据 + Lua 滤镜；
4. 复制 `weasel.dll` 到 System32 / SysWOW64，导入 TIP / CLSID 注册表；
5. 托盘与输入法切换条显示「三生输入法」+ 金环三生图标；
6. 编译部署配置（首次约 10—60 秒）；
7. **把三生加进当前用户的键盘列表**——装完直接 `Win+空格`（或 `Alt+Shift`）就能切，不用再去「设置 → 时间和语言」手动添加，也不用注销重启。v1.9.9 起改用系统 `input.dll!InstallLayoutOrTip`，并在写入后复查；失败会明确提示而不是假报成功。

卸载：`控制面板 > 程序和功能 > 三生输入法 > 卸载`，或开始菜单「三生输入法 > 卸载三生输入法」。
卸载只删三生自己放进去的东西，**用户词库与打字记录一律保留**（要连词库一起清，用 `卸载三生输入法.cmd`，它会先列清单再动手）。如果卸载前三生已被官方小狼毫重新覆盖安装（共享组件归官方），**控制面板/开始菜单里的卸载器**只移除三生专属的工具、图标、开始菜单和登记，**不会碰官方输入法本体、系统 DLL 与 TIP**；`卸载三生输入法.cmd` 是强力清理工具，默认只预演，真删前请看清清单。

旧版 `install.bat` 仍保留，仅供不想装 exe、想手动铺文件的场景。

想自己改配置或重新打包（NSIS 一键重建 `setup.exe`）：见 [docs/构建与发布.md](docs/构建与发布.md)。

## 升级说明

三生输入法 = Rime 引擎 + 配置层（我们的东西）。

| 升级什么 | 怎么做 |
|---------|--------|
| **三生输入法本身**（配置/图标/滤镜更新） | 下载新版 `setup.exe`，直接双击覆盖安装即可；安装器会先把旧配置备份成 `sansheng-backup-时间戳`，自造词和调频记录不会丢 |
| **Rime 引擎**（小狼毫官方升级） | 直接运行新版官方小狼毫安装包，装完再运行三生 `setup.exe`。v1.9.9 起会识别官方版并自动接管，**不需要先手动卸载**，用户词库和配置会先备份保留。顺序不要反：新版官方会重写共享 DLL 和 TIP，反过来的话要再跑一次三生安装器才能回到三生。 |

**关于降级**：三生内置的是小狼毫 0.17.4 引擎。若本机装过更新的官方小狼毫，覆盖安装会把引擎统一到 0.17.4（词库与配置保留），这是为了保证三生配置层的兼容性。若必须使用更新的官方引擎，请以官方版使用；三生的配置层目前只随 0.17.4 发布包提供。

## 设计原则（踩坑总结）

1. 独立文件，绝不整文件替换 `inputShow_Filter.lua`（dsh 旧方案「修一个坏一个」）。
2. 全程 `pcall` + `cand:get_genuine().comment`，任一候选出错不影响输入，**调频/自造词不受影响**。
3. 只改 `comment`，不改候选顺序与身份。
4. **绝不手动往词典里塞词**——遵循 Rime 自动组词（连续上屏后写入 `user.txt`，反查自动读取）。
5. `user.txt` 的 `enc*` 自动编码条目不是规范五笔码，已过滤，不参与反查。

## 已知边界（诚实标注，非缺陷）

- **二进制 userdb 自造词读不到**：Rime 自动组词写入 `.userdb` 的词为二进制，滤镜加载阶段读不到，故这类自造词不显示反查码（方案层限制，非滤镜问题；调频本身不受影响）。
- **罕见字缺拼音**：如 𧟴（U+277F4，五笔码 `gmbq`）是真实字符，仅因拼音词库未收录而无拼音反查。
- **自造词撞车**：`user.txt` 里 Rime 自动生成的 `enc*` 占位码非规范五笔码，被过滤；其自然码可能已被真实词占用（如 `pxra` = 它找）。
- **英文候选的中文释义取决于词库收录**：「中英对照」滤镜（开关 `encnDic`，默认开）会给英文候选补中文释义，实测 `apple → 【apple】n.苹果`、`he → 【he】pro.他`；其字典 `dic_4w_en.txt` 共 39,814 条，以**单词**为主，所以多词短语（`seed pod`、`to save`）和动态候选（CPU / 系统名一类）查不到，就没有释义。

     窗口秒关。`检查更新.cmd` / `卸载三生输入法.cmd` 改为 **GBK + CRLF、不带 `chcp`、末尾 `pause`**，报错也会停住给人看。
     （v1.9.2 里那个双击卸载的壳其实是坏的，控制面板与 `uninstall-sansheng.exe` 不受影响。）
  4. **「检查更新」入口**（开始菜单 ▸ 检查更新）：读本机注册表版本 + 问一次 GitHub 线上最新版，只报结果不动你的系统。
     有新版本时给三个选择——自动下载安装包 / 只打开下载页 / 先不弄；**自动下载这条会先把文件大小与
     SHA-256 和 GitHub 公布的 `digest` 逐一比对，校验不过绝不做下一步**。不需要管理员权限。
  5. **卸载不再弹「需要重启」**：`weasel.dll` 被 explorer 等进程加载，当场删不掉，以前排队下次开机删除时会置上
     NSIS 的重启标志。现在照旧排队、由系统下次开机删掉，但紧跟 `SetRebootFlag false`，不再提示重启。
  6. **Shift 中英切换时光标处的气泡图标**：找到正规开关——`WeaselServer` 读
     `schema/zhung_icon`（中文态）/ `schema/icon` / `schema/ascii_icon`（英文态）等五项，取值是「用户资料夹根目录下的
     `.ico` 文件名」，**不用改 exe**。做成圆形徽章：中文态 = 黑底金圈 + 金色「三」，英文态 = 同一块圆盘 + 金色加粗「A」
     （气泡底色是浅灰，透明底金条对比不够）。按圆盘半径把圆外像素 alpha 清 0 再 1px 羽化，才是真圆而不是黑方块。
  7. **部署调用钉死全路径** `"$INSTDIR\weasel-0.17.4\WeaselDeployer.exe" /deploy`：以前只给裸文件名，
     解析不到时 NSIS 不一定报错、返回码照样 0，静默白跑——而气泡图标正是靠部署把配置编译进 `build/` 才生效的。

  1. **已装官方小狼毫时直接接管**：识别 32/64 两个注册表视图，调用官方 `WeaselSetup.exe /u`，清掉官方卸载登记、自启和开始菜单，在**原安装目录**覆盖安装；原有配置先备份，词库与 `user.txt` 不动。接管后把官方 WinSparkle 自动更新关掉（`CheckForUpdates=0`），避免它把三生升回官方版。
  2. **修掉键盘列表被清空的致命参数错误**：旧安装器调用 `enable-tip.ps1` 时把 TIP 写成 `0804{...}`，少了一个冒号（应为 `0804:{...}`）。Windows 会把这个无效项连同该语言下已有的键盘一起清掉，表现就是「装完切不出三生」。现在改用系统 `input.dll!InstallLayoutOrTip`，参数先做格式校验，写入后再读一次复查；失败会明确告警并以退出码 2 结束，不再假报成功。
  3. **卸载器保护官方版**：如果装完三生后又跑过官方安装包，共享 DLL/TIP 已归官方，此时卸载三生只移除三生专属的工具、图标、开始菜单和登记，不碰官方输入法本体；三生图标即将删除时同步清掉 TIP `IconFile`，不会留下指向空文件的图标。
- **v1.9.10（2026-10-20）**：**一版一号**，v1.9.9 的全部修复原样保留（万能五笔乱码词库、接管官方小狼毫、TIP 冒号修复、卸载保护官方版、图标清理）。本版补两件事：
  1. **升级不再覆盖用户自造词**：`Custom_phrase.txt` 是用户数据，安装器现在只在文件不存在（全新安装）时写模板；已有文件原样保留。旧安装器会用 `File /r` 直接覆盖成空白模板，虽然备份里还有，但用户未必知道去 `sansheng-backup-时间戳` 里找。
  2. **出包前硬校验 TIP 参数**：`prepare_release.py` 会扫描所有 `-Tip` / `TipStr`，必须以 `0804:` 开头；缺冒号直接判为禁止发布，防止再次出现「装完输入法，用户原有键盘列表被清空」的致命错误。v1.9.9 本地测试时就是这条参数写错，导致本机的万能五笔、搜狗五笔、青简从键盘列表消失；程序本身没被卸载，重新写回 TIP 即可恢复（本机已恢复并验证）。
