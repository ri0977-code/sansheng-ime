## 托管建议

优先级从高到低：

1. **AGC 云托管**：与提审同平台，链接稳定，不需要自己买域名。
2. **华为云 OBS / 对象存储静态网站**：需要主人账号，费用低。
3. 其他可公开访问的静态托管：必须支持 HTTPS，且国内可正常打开。

不建议使用需要登录、会弹广告或带下载拦截的免费托管。发布后把两个 URL 写入 `docs/OWNER-ACTIONS.md` 与 `agc-privacy-form.md`。

## 隐私口径（不可写反）

- 输入内容只在本机处理，不联网、不上传。
- 应用未声明 `ohos.permission.INTERNET`。
- 仅声明 `ohos.permission.VIBRATE`。
- 无账号、无广告、无统计/崩溃 SDK、无云同步。
- 用户词典与自造词只存应用沙箱，清除数据或卸载即删除；中英/简繁模式是引擎运行期状态，不落文件。
