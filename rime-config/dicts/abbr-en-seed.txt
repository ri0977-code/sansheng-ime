#
# 格式：词面<TAB>输入码<TAB>中文释义
# 词面 = 上屏时真正打出来的样子（大小写混排都合法：CPU / iOS / WeChat）
# 码   = 用户在小写中文态敲的那串字母（必须纯 a-z，数字与符号进不了表典）
# 释义 = 只在自测与文档里用；上屏注释交给现有 dic_4w / 反查滤镜，不在这张表里重复造
#
# 收录尺子（四条同时满足才收）：
#   1. 固定写法：业界/大众公认这样拼，不是临时缩写（收到「人工智能」的 AI，不收任意首字母）
#   2. 中文态常用：打字场景是「在中国打字法里突然要冒出的那个英文词」
#   3. 现在打不出来：本地已核 dic_4w_en.txt 无 CPU/NBA/PDF/APP/PPT，easy_en 里只有 CPU\tCpu 那种
#      需要大写键才能命中的条目，且 easy_en 方案根本不在 schema_list 里
#   4. 码不含数字：5G / B2B / O2B / P2P / PM2.5 / IPv6 这类进不了表典（数字键被选词占用），
#      只能走 symbols 或 v 模式，另列「不收」清单
