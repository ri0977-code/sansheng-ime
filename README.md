# 三生输入法 Sansheng IME

![icon](assets/icon-trigram-A-256.png)

> **乾卦 ☰ = 三阳爻，三生万物。**
> 图标直接取《周易》乾卦符号：三道等长阳爻并立，开天、刚健、生生不息；三生即**五笔 · 拼音 · 英文**全向混输。

Rime「**五笔 · 拼音 · 混输 · 简繁**」全能输入法的增强滤镜：给候选加 **三向编码反查**、**多音字注释**、**简繁切换**与**自调频**，完全不改输入法原文件，独立 Lua 滤镜，安全可卸。

原名「五笔词通」，2026-10-15 更名为「三生输入法」。

## 三向真·反查（核心能力）

按输入类型回显对方那套码，不误伤「五笔码含元音键」的常见字（不=i、有=e、和=a 等）：

- 打五笔 `vb` → 好 显示 `hao`（只回显拼音）；
- 打拼音 `hao` → 好 显示 `[vb]`（只回显五笔码）；
- 打英文 `good` → 好 显示 `hao [vb]`（查义场景给「拼音 + 五笔码」最全信息）。

其他能力：简繁反查（繁体候选同样可反查）、自造词反查（user.txt 真实词条）、
多音字注释（打 `ta` → 长 显示 `zhang/chang`）、保留上游词性/释义（💡）与拼音（✔）注释、
反查码前置不被截断、碰撞检测杜绝误导性假码（现算码被真实词占用则隐藏）。

### 反查来源与准确性

- 五笔码只显示两种**可靠**来源：① 词库实码（wubi86 / 万能五笔自造词 / user.txt 真实词条）；
  ② 按标准五笔组词规则现算的码，但若该码已被另一个多字词占用则隐藏。
- 拼音来自全量拼音词典 `cn_pinyin_wp`；生僻字无拼音收录时只显示五笔码，属正常。

## 自调频（v1.7 新增）

选词即学习，上屏即记忆——三档机制：

| 档位 | 机制 | 状态 |
|------|------|------|
| 自动档 | Rime 用户词典 userdb：每次选词 / 连续上屏都记录，同输入下已选候选自动提频前置 | ✅ 默认开启（`enable_user_dict` + `encode_commit_history`） |
| 手动档 | `Custom_phrase.txt` 置顶自造词：`initial_quality: 1`，永远排最前 | ✅ 随包附模板 |
| 重置档 | `reset-tune.bat`：一键清空学习记录，从头再学（删前自动备份） | ✅ 随包附工具 |

**兼容承诺**：三生滤镜只改 `comment`、永不动候选顺序与身份——调频 / 自动组词机制不受滤镜影响（已真机验证）。

## 安装

**方式一（推荐，一键）**：运行包内 `install.bat`——自动备份 Rime 目录、装滤镜、接好
`rime.lua` / `wubi_pinyin.custom.yaml`、复制 OpenCC 简繁数据、放入自造词模板。完成后
右键小狼毫托盘 →【重新部署】。

**方式二（手动）**：

1. 备份你的 Rime 目录（`D:\Program Files\Rime` 或 `%APPDATA%\Rime`）。
2. 复制 `codeLookup_Filter.lua` → Rime 主目录的 `lua/` 子目录。
3. `rime.lua` 末尾追加：`codeLookup_Filter = require("codeLookup_Filter")`。
4. `wubi_pinyin.custom.yaml` 的 `engine/filters:` 中，`pinyinAdding_Filter` 之后插入：
   ```yaml
   - lua_filter@codeLookup_Filter
   ```
5. 确保 OpenCC 简繁数据在 Rime 搜索路径内（`opencc/s2t.json` + `STCharacters.ocd2` + `STPhrases.ocd2`，见包内 `opencc/`）。
6. **重新部署**：Rime 托盘图标 →【重新部署】。

## 设计原则（踩坑总结）

1. 独立文件，绝不整文件替换 `inputShow_Filter.lua`（dsh 旧方案「修一个坏一个」）。
2. 全程 `pcall` + `cand:get_genuine().comment`，任一候选出错不影响输入，**调频/自造词不受影响**。
3. 只改 `comment`，不改候选顺序与身份。
4. **绝不手动往词典里塞词**——遵循 Rime 自动组词（连续上屏后写入 `user.txt`，反查自动读取）。
5. `user.txt` 的 `enc*` 自动编码条目不是规范五笔码，已过滤，不参与反查。

## 已知边界（诚实标注，非缺陷）

- **二进制 userdb 自造词读不到**：Rime 自动组词写入 `.userdb` 的词为二进制，滤镜加载阶段读不到，故这类自造词不显示反查码（方案层限制，非滤镜问题；调频本身不受影响）。
- **罕见字缺拼音**：如 𧟴（U+277F4，五笔码 `gmbq`）是真实字符，仅因拼音词库未收录而无拼音反查。
- **自造词撞车**：`user.txt` 里 Rime 自动生成的 `enc*` 占位码非规范五笔码，被过滤；其自然码可能已被真实词占用（如 `pxra` = 它找）。
- **英文候选中文释义反查**（可选，未做）：如需可扩展。
