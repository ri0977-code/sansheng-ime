## 1. 五张怎么拍

### 01 · 26 键打拼音（`01-pinyin-26.png`）
1. 打开任意可输入的 App（记事本），点输入框唤出三生键盘。
2. 依次点 `n i h a o`。
3. **屏上应该是**：L1 反查行 `nihao · wqvb`；L2 候选行「你好 / hello / 你 / 拟 / 尼」。
4. 拍。
- **不合格**：L2 候选行里出现 `[wqvb]` 这种括号码 ⇒ 说明装的是旧包（源码 `KeyboardIndex.ets:8-9` 明确「行内不放 comment」）。

### 02 · 九宫格三向（`02-t9.png`）
1. 点 `?123` → 符号页 → 点 **12/34** → 进九宫格。
2. 依次点 `6 4` `4 2 6`（得到 `64 426`）。
3. **屏上应该是**：L1 行 `64 426 · ni hao`；L2 候选「你好 / 你敢 / 米高 / 你 / 嗯」。
4. 拍。
- **不合格**：九宫格不是严格 3×3、或底栏出现第 7 个键 ⇒ 回 H-107。

### 03 · 展开候选网格（`03-grid.png`）
1. 回到 26 键，输入 `nihao`（有候选）。
2. 点**候选栏最右端的 ⌄**（空闲态是收起箭头；有候选时点它展开，图标变 ⌃）。
3. **屏上应该是**：网格覆盖键盘区，**每一格上方各自带该词的码**（`wqvb 你好`、`hello hello`、`rny 拟`）。
4. 拍。
- **不合格**：网格里没有逐格码 ⇒ 与商店文案「每格带码」不符，**这张不能交**。
- 注意：这一步同时验证 H-109（有候选时点三角＝展开）。**方向别写反**：点之前是 ⌄，展开后才是 ⌃；`KeyboardIndex.ets:1060-1090`。

### 04 · 符号面板（`04-symbol.png`）
1. 点底栏 `?123`。
2. **屏上应该是**：符号页，底栏 `ABC｜,｜12/34｜空格｜.｜⏎`（符号页没有 🌐）。
3. 拍。
- **空格键面**：当前代码两处都是「空格」（`KeyboardIndex.ets:2213/2414`）。若最终包里 H-154 P2-1 已落地改成「三生」，这条与 `listing.md` §5 一起同步改，并以实拍为准；数字键盘的「空」不变。

### 05 · 应用首页（`05-home.png`）
1. 回到桌面 → 点三生输入法图标进 App。
2. **屏上应该是**：版本号 1.0.0、启用方法、试一试输入框、隐私政策／用户协议／关于三个入口；**没有「设置」入口**（H-090 已摘）。
3. 拍。
- **不合格**：出现设置入口 ⇒ 装的是旧包。
