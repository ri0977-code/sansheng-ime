# 三生输入法 · 安卓版 v1.9.8-android · 安装说明

三分钟装完。整个过程就三步：**装两个 apk → 导入词库包 → 启用键盘**。

---

## 你要下载哪个文件

**只下载 `三生输入法-安卓-v1.9.8-android.zip` 这一个就够了**，里面按编号装好了全部东西：

```
1-先装这两个apk/          ← 第 1 步用
2-再导这个（别解压）/      ← 第 2 步用，里面就是那个「导入包」
3-备用-手动放置的词库/      ← 只有导入失败时才用
安装说明.md
README.md
```

传到手机后，用自带的「文件管理」长按它选**解压到当前目录**（或者在电脑上解压，再把里面的东西传过去）。

> 如果你已经装过那两个 apk，只需要 `三生输入法-安卓-v1.9.8-android-导入包.zip` 这一个文件。

## 先看这一条：你的手机能不能装

| 你的手机 | 能装吗 |
|---|:-:|
| 安卓手机（小米、三星、OPPO、vivo、荣耀，以及**鸿蒙 4.2 及更早**的华为/荣耀） | ✅ 能 |
| **纯血鸿蒙**（HarmonyOS NEXT / 5.0 以上，例如 Mate 80） | ❌ 不能 |
| x86 平板、电脑安卓模拟器 | ❌ 不能（本包只含 arm64） |

纯血鸿蒙不是「装不上」，是系统里已经没有安卓兼容层，**任何 .apk 都装不了**，只能装 .hap。
「卓易通」这类工具能在纯血鸿蒙里跑安卓 App，但输入法必须注册成系统键盘，沙盒里注册不上，所以帮不上忙。

> 本包的导入流程已在 x86_64 安卓模拟器上按真实点击路径实测通过（2026-10-19）。
> 真机（鸿蒙 4.2 的 nova 6 5G 等）尚未回测，如果哪一步和这里写的不一样，请告诉我。

## 第 1 步：装两个 apk（顺序不能反）

进解压出来的 `1-先装这两个apk` 文件夹，两个文件：

1. 先装 **`org.fcitx.fcitx5.android-0.1.3-...apk`**（43.8 MB）—— 键盘框架，装完手机上显示的名字可能是「小企鹅输入法」
2. 再装 **`org.fcitx.fcitx5.android.plugin.rime-0.1.3-...apk`**（5.5 MB）—— 三生词库靠它跑

> 主程序没装的时候插件装不上，所以一定要先装大的那个。
> 装的时候如果提示「未知来源」，允许即可。
> 装完**打开一次** fcitx5，让它把数据目录建好，再往下走。

---

## 第 2 步：导入词库

用 `2-再导这个（别解压）` 文件夹里的 **`三生输入法-安卓-v1.9.8-android-导入包.zip`**。

**不要解压、不要改名字，整个文件直接用。**

1. 把这个 zip 传到手机（数据线、微信文件传输助手、网盘都行），传到「下载 / Download」文件夹最省事
2. 打开 **fcitx5** → 右下角**齿轮（设置）** → 列表拉到底点 **「高级」**
3. 点 **「导入用户数据」** → 弹窗点 **「确定 / OK」**
4. 在文件选择界面找到这个 zip，**点它的文件名那一行**（点图片那块会进预览），选中后会自动开始导入
5. 等几十秒（词库约 20 MB）

> 找不到「导入用户数据」？它在「高级」页面最底下，往下滑。
> 这个功能名字有点唬人，其实就是「把配置灌进去」，不会动你手机里别的东西。

**万一导入失败**（提示格式错误、找不到文件）：用能访问 `Android/data` 的文件管理器（MT 管理器 / X-plore），
把 `3-备用-手动放置的词库` 文件夹里的**全部内容**放进：

```
Android/data/org.fcitx.fcitx5.android/files/data/rime/
```

或者电脑插数据线执行（在当前目录下能看到 `3-备用-手动放置的词库` 文件夹）：

```
adb push "3-备用-手动放置的词库/." /sdcard/Android/data/org.fcitx.fcitx5.android/files/data/rime/
```

## 第 3 步：启用键盘

1. 手机 **设置 → 系统 → 语言和输入法 → 管理键盘**（各品牌叫法略有差别，找「输入法」就行）
2. 把 **fcitx5** 的开关打开，弹出提示选「允许」
3. 随便点一个输入框把键盘调出来，点键盘**左下角的地球键**
4. 切到 **「五笔·拼音」**（空格键上会显示 `Rime (五)`，看到这行就说明词库加载成功了）

## 开关在哪里（安卓没有 F4）

桌面版按 F4 弹菜单，安卓没有 F4，改成这样：

**点输入框调出键盘 → 键盘工具栏最左边的 `>` → 点 `…`**

会出来一排磁贴，每个磁贴**上面那个大字是当前状态，下面那行字是「再点一下会变成什么」**：

| 磁贴 | 作用 |
|---|---|
| 繁體 → 简体 | 简繁切换（本版已实测可用） |
| 中英对照 → Off | 英文候选旁边出中文释义 |
| commentOn → Off | 候选词注释的开关 |
| 半角 → 全角 / 常用 → 增廣 / 。，→ ．， | 和桌面版同名开关 |
| Reload Config | 改过词库后不用重启，点这个重读配置 |

## 出问题对照这张表

| 现象 | 为什么 | 怎么办 |
|---|---|---|
| apk 提示「未安装 / 解析包出错」 | 纯血鸿蒙不支持 apk；或手机不是 arm64 | 见开头那张表 |
| 导入报 `xxx.lua: open failed: ENOENT` | 用的是 10-19 18:00 之前打的旧包 | 重新下载本版导入包，已修 |
| 导入报 `Unable to find metadata of user data` | 自己压缩的 zip 不是 fcitx5 备份格式 | 用本包的导入包，别自己压 |
| 导入后没有「五笔·拼音」方案 | 部署还没跑完 | 磁贴面板点 Reload Config，或杀掉 fcitx5 重开，等 30 秒 |
| 候选框空白 / 打不出字 | 某个滤镜加载失败 | 见下面「定位」一条 |
| 只有英文没有中文 | 切到别的方案了 | 地球键切回「五笔·拼音」 |
| 简繁切换没反应 | — | 本版已实测可用，先确认你走的是上面「开关在哪里」那套路 |

**候选框空白的定位法**：把 `rime/wubi_pinyin.custom.yaml` 里 `engine/filters` 下面，除了
`simplifier@tradition`、`lua_filter@inputShow_Filter`、`uniquifier` 三行以外的行删掉，再导入一次。
能出字就说明是某个滤镜的问题，把结果告诉我，我来定位。
