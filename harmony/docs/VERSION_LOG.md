# 版本演进表

> 工程版本与 App 清单版本是两套：工程版本用于内部里程碑；App 的 `versionName` 暂时保持 `1.0.0`，避免真机安装时降级失败。到 M5 再统一。

## 记录规则

- 每个**真机可安装**的构建必须有一行。
- 必须写清：工程版本、日期、git commit/tag、构建结果、真机结果、HAP 路径、已知问题。
- 没上真机的构建写「仅构建，未装机」，不要写成已验证。
- 回滚时新增一行，不删旧行。
